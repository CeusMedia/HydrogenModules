Synchronization with calendar applications

Tasks and events can be imported into calendar applications, for example:

  • Mozilla Thunderbird
  • Apple iCal
  • Microsoft Outlook

Instructions for Mozilla Thunderbird:

  • copy this link to the clipboard
  • open Mozilla Thunderbird (the Lightning extension must be installed)
  • menu: File -> New -> Calendar
  • select source "On the Network", next
  • select format "iCalendar (ICS)", enter the copied link as location, next
  • choose a name (e.g. "Tasks and Events") and a color for the event blocks
