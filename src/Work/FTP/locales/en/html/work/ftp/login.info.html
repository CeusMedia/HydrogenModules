FTP connection

To see the files on the server, a connection to the FTP server has to be established. Please enter your access data here:
Host
IP address or DNS name of the FTP server.
Port
Port number of the FTP server, usually 21.
Path
Path on the server, usually empty.
User
Name of the FTP user, on public servers anonymous is often possible, too.
Password
Password of the FTP user, only empty for user anonymous.

Saving the connection

The connection is lost on logout.
To have the connection established automatically, you need to save your access data in your module settings.
