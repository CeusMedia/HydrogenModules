Explanation

Readers are organized into topic groups.
This makes it possible to send a campaign to only a part of the readers.

On registration, readers are assigned to the automatic topic groups by default.
Optionally, the reader can select further "normal" topic groups.

There are the following types of topic groups:
normal
can be selected on newsletter registration
mandatory
is assigned automatically on registration
hidden
internal topic group for segmentation
testing
contains readers only for testing prepared campaigns
